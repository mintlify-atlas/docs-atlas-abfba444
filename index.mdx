## What is World Bits?

World Bits is a 2D side-scrolling platformer where the player navigates through a level-select hub and chooses from three story levels or an endless runner mode. The game features:

- **Three story levels** — hand-crafted platform stages with a countdown timer, collectibles, and enemy encounters
- **Infinite runner mode** — procedurally assembled tile maps that scroll forever; survival and cherry counts are saved as your high score
- **Pixel-art visuals** — SunnyLand artwork pack with animated player states (idle, run, jump, hurt, climb)
- **Dynamic day/night cycle** — backgrounds transition through morning, day, afternoon, and night colors in real time
- **Enemy variety** — patrol walkers, player-tracking AI, and a jumping bear each with configurable parameters
- **Checkpoint system** — progress saved via Unity PlayerPrefs so the game respects your last saved position

<Steps>
  <Step title="Install Unity 2022.3.7f1">
    Download Unity Hub and install Unity Editor version **2022.3.7f1** with the **2D Game Development** workload.
  </Step>
  <Step title="Open the project">
    Clone the repository and open the root folder in Unity Hub. Unity will resolve all packages automatically from `Packages/manifest.json`.
  </Step>
  <Step title="Open the Menu scene">
    In the Project window, navigate to **Assets → Scenes** and open `Menu.unity`. Press **Play** to launch the game.
  </Step>
  <Step title="Start playing">
    Use **Arrow Keys** to move, **C** to jump, and **X** to run. In the hub world press **Up Arrow** near a level door to enter it.
  </Step>
</Steps>
